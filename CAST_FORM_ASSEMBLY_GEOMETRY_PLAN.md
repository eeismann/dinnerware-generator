# Cast Form Assembly Geometry Plan

## Corrected Target

The current clean hexagonal assembled wall footprint is not the target. The
target is the existing mold body plus additive exterior seam stock at every
wall-to-wall joint.

The added stock must become real wall-mold volume. It is not a visual overlay,
not a top cap, and not another side-stock removal. The shelf, inner vessel
relationship, wall height, and base/cavity relationship must stay unchanged.

## Geometry Goals

1. Preserve the current vessel-facing and shelf surfaces exactly.
2. Add exterior seam/corner extensions to every split wall mold.
3. Keep exterior wall faces flat, with side/back wall intersections resolving
   as orthogonal mold-body corners where the target requires flat walls.
4. Give each seam extension explicit ownership so adjacent wall molds meet
   cleanly at explosion distance `0` without occupying the same volume.
5. Keep `Corner Cut Width = 100 mm` as the required verification setting, but
   stop treating it as proof that all exterior stock outside the side cut planes
   must be removed.

## Architecture

- Keep the volume-first wall compiler as the active generation path.
- Modify `scripts/castForm/geometry/wallVolumeCompiler.js` in the connected wall
  topology path. This is where the top-down wall footprint is built row-by-row.
- Treat the old side-cut-plane behavior as the source of the current failure:
  it creates the clean hexagonal footprint by cutting away the material that now
  needs to exist.
- Do not blindly enable `experimental.perpendicularSideWalls`. A geometry probe
  showed that this barely changes the `cornerCutWidth = 100 mm` footprint and
  produces odd broad-wing behavior when the cut is removed.
- The implemented geometry keeps the connected wall topology and promotes the
  additive stock into the wall footprint itself. When additive seam stock is
  active, the old side-cut planes become reference planes for validation, not
  clipping planes for the exterior boundary.
- The corrected exterior footprint is the old body plus the full missing
  side/corner region. For the provided STL at `Corner Cut Width = 100 mm`, the
  old cut removes about 75 mm of side/corner depth, so a shallow bounded patch
  of roughly 34 mm is explicitly insufficient.
- The outer-radius calculation must therefore generate the full flat-wall
  footprint directly. The stock is not a separate patch polygon, detached
  prism, top cap, or post-process overlay.

## Validation Goals

The corrected gates must prove the desired geometry, not merely prove that walls
do not overlap.

1. Load the provided mug STL.
2. Generate three wall molds.
3. Set `Corner Cut Width` to `100 mm`.
4. Use the connected wall topology path.
5. Fail if the top-down silhouette matches only the clean hexagonal footprint.
6. Pass only if each wall has additive exterior seam stock beyond the current
   cut footprint as generated envelope surface, not just two point vertices.
7. Pass only if the assembled walls at explosion distance `0` do not overlap
   beyond tolerance.
8. Keep mesh-quality and export topology checks in the validation chain.

## Execution Goals

1. Geometry ownership: the added corner/seam stock must be generated by the
   wall envelope math, not by a separate patch mesh or detached prism. Evidence:
   the side-cut planes are bypassed as exterior clipping planes in
   `computeOuterRadius()` when additive seam stock is active, and the old
   point-prism path is not active. The additive gate must also prove each wall
   mesh is one connected surface component.
2. Shape fidelity: the output must match the squared, flat-side target rather
   than the clean hex, long spike, broad triangle, or tiny point-patch variants.
   Evidence: every wall side restores most of the side/corner depth removed by
   the old cut plane, with enough generated envelope vertices to prove it is
   part of the wall surface.
3. Assembly correctness: all three walls must come together at
   `explosionDistance = 0` without overlap. Evidence: the assembled top-down
   gate samples multiple height slices and reports zero overlap.
4. UI proof: the internal Codex browser must load the provided STL at
   `cornerCutWidth = 100`, `wallCount = 3`, `camera = top`, and
   `explosionDistance = 0`. Evidence: DOM validation attributes and screenshots
   from the in-app browser/artifact output.

## Agent Tracks

- Geometry auditor: independently inspect the compiler to verify the new stock
  is native to the wall envelope and does not alter the inner/shelf surfaces.
- Validation auditor: independently inspect the gates and artifacts to check
  that they reject the old wrong outcomes and prove the desired positive case.
- UI-proof auditor: independently inspect the internal-browser validation path,
  URL parameters, DOM hooks, and proof artifacts for reliability gaps.

## UI Proof

The final visual proof must use the internal Codex browser, not Chrome.

Verification URL shape:

```text
http://127.0.0.1:5173/cast-form-generator/?devStl=/output/fixtures/untitled_mug_6.stl&cornerCutWidth=100&wallCount=3&view=exploded&explosionDistance=0&camera=top
```

The UI proof should set or confirm:

- `Corner Cut Width = 100 mm`
- `Wall Count = 3`
- top-down camera
- assembled walls at the origin
- explosion distance `0` if the UI is in exploded mode

The screenshot must show additive seam stock around the wall joints. A clean
hexagonal assembled footprint is a failure, and a broad single-triangle
assembly is also not the intended endpoint.
