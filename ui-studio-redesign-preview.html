Studio Shell — design spec v4

Concept

The viewport is the app. The docked header and footer are gone; every control floats over the canvas as a translucent island (blur 24px, radius 14, hairline border) and can get out of the way.

v4 changes from your feedback

  • Warnings → lower-left UI — pulled back out of the panel into a dedicated bottom-left chip ("⚠ N warnings") that expands a popover. Only shown when warnings exist (Cast Form here; Dinnerware/Vessel V2 have none). The panel footer keeps just the item/part/point count.
  • Case Box is its own mode — the Polymer Case Box moved out of the Mold panel into a dedicated toolbar icon. Clicking it switches the app to a case-box editor: the canvas shows the open polymer box (pour spout, registration channels, alignment tabs, dimensions) and the panel swaps to Case Box / Dimensions / Features. The Parameters icon returns to Mold Setup.

v3 changes

  • No bottom chrome — the black bar was the preview-only screen switcher; it's now a slim harness strip at the very top, visually distinct so it never reads as product header/footer. The product's own header (top-center pill) owns home / filename / global actions.
  • Everything folds into the left panel — the floating status chip, warnings popover, exploded control, view-mode toggle, and point editor are gone from the canvas; they now live inside the left panel (with a status footer). The canvas bottom stays clear.
  • Left panel is app-specific — Dinnerware: Scaling / Style / Pattern / Proportions / Overrides. Cast Form: Input / Configuration / Case Box / Assembly (exploded) / Warnings. Vessel V2: Selected Point / View mode / Revolve / Curve / Wall.

v2 changes

  • Tool rail docking — the right tool rail is a persistent right-edge island. When the panel opens it animates 284px left (panel 272 + 12 gap) to sit just left of the panel, and never overlaps it. Panel is always to the rail's right.
  • Left cluster order — toolbar pinned to the top-left corner; the Parameters panel opens to its right (x72); the view cube docks to the right of the cluster and slides right (+312px) to stay right of the panel when it opens. Order: toolbar → panel → cube.
  • Icons pruned to real features — removed invented tools (search/add/transform/move/scale/align/mirror/wrench/display/screenshot/history/undo/redo/new-group). What's left maps 1:1 to the codebase.
  • View cube enlarged (80px) and grouped tight above the axis gizmo, matching your close-up.

Real control inventory (per tool)

  • Shared left rail — Parameters, Cross-section, Grid, Canvas-tone. (all exist today)
  • Camera — view cube + reset (maps to Top/Side/¾/Bottom/Reset in viewport.js).
  • Top bar — Home, project name, Export, ⋯.
  • Dinnerware — no right rail; editing is the Parameters panel, visibility is the Items panel. Nothing floats without a job.
  • Cast Form — right rail = Import (STL/OBJ); bottom-right = Exploded island (switch + separation slider).
  • Vessel V2 — right rail = pen tools (Select / Add point / Convert node / Delete); bottom-right = Profile ↔ Revolved view toggle.

Vessel V2 point configurator

  • Canvas is the 2D profile editor: dashed revolve axis, the profile curve, draggable nodes, and a faint mirror of the curve to read the revolve.
  • Bezier handle UI — the selected node shows two accent handle arms with round grips; drag to shape tangents.
  • Point configurator (bottom-center island, appears on selection): node Type (Corner / Smooth / Symmetric), R/H position, and handle Len/∠. This is the bezier "handle" panel.
  • Points panel (right) lists every node with its type badge; selecting a row selects the node and vice-versa.

Migration notes

  • Islands are plain divs over the existing Three.js viewport; the cube maps to camera presets in scripts/ui/viewport.js.
  • Items panel replaces the footer Items menu (checkboxes → eyes); warnings become the status popover.
  • Vessel V2 point editor drives the existing profile/point state; the configurator writes the same node model that vessel-v2 revolves.
  • Theme vars extend styles/themes.css; localStorage schema untouched. Focus mode is a body class + ~20 lines of JS.
