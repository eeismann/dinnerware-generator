Surface Pattern Emulator — 30 parametric motifs on the revolved wall

Every vessel is a 2D profile revolved around the vertical axis. A surface pattern is a height field displaced along the profile's outward normal — one engine, driven by angle θ and height t. Change the function, change the motif. Below is an exhaustive, live gallery of pattern families, each rendered as real geometry on the same vessel. Click any tile to open it interactively and dial its parameters.

The one engine behind all of them

For each point on the wall we compute a signed offset and push the surface in/out along its normal. Patterns differ only in how the offset depends on where you are around the pot (θ) and how high (t):

r'(θ,t) = r(t) + A · D(θ,t) · fade(t) // along 2D normal (n_r, n_h) longitudinal D = f(N·θ) flutes, reeds, facets, lobes latitudinal D = f(M·t) rings, bamboo, terraces helical D = f(N·θ + k·t) twist flutes, rope, screw lattice D = g(N·θ) · g(M·t) hobnail, bead, knurl, hex organic D = noise / worley(θ,t) hammered, bark, crackle

Why this taxonomy is exhaustive

Any wall decoration reduces to which variable it repeats along and what waveform repeats. Repeat around → vertical family. Repeat up → horizontal family. Repeat along a tilted axis → helical. Repeat along both → lattice. Break periodicity with noise → organic. Beat two frequencies → undulating/moiré.

Everything survives STL export because it is a watertight displaced grid — the same reason knurling on cups is done with displacement, not booleans, in Fusion 360 & friends.
