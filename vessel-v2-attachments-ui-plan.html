Attachment system plan

Variables first, then UI rules and implementation order

Keep every addition in its own state namespace. The base profile remains the source of truth for surface radius, mouth diameter, height limits, and attachment intersections.

Spout variables

style / pathModePreset plus editable Bezier or straight-rounded centerline. mountHeight / azimuthPlacement on the sampled Vessel 2 exterior profile. pathPoints[]Position, in/out handles, point kind, and per-point corner radius. length / riseOverall reach and outlet height relative to the vessel rim. rootWidth / rootHeightOval attachment footprint and throat aperture. mouthWidth / mouthShapeRound, oval, pinched, flared, or knife-edge outlet. wall / blendRadiusSpout shell thickness and vessel-junction fillet. cutAngle / strainerOutlet trim and optional hole array at the throat.

Handle variables

pathModeBezier or straight-rounded, using the Vessel 2 editor interaction model. pathPoints[]Any number of points; each stores x/h, in/out handles, kind, and cornerRadius. attachments[]Vessel height, azimuth, pad width/height, embed depth, and blend radius. crossSectionRound, oval, rounded rectangle; width, depth, and corner radius. twist / taperCross-section rotation and scale along the swept path. sweepSegmentsPreview/export sampling quality kept separate from the editable path.

Lid variables

fitTypeInset gallery, overlapping skirt, or direct-on-flange. profilePoints[]Bezier or straight-rounded lid profile, derived initially from mouth diameter. seatWidth / seatDepthGallery ledge geometry that supports the lid. innerFlangeDepth, thickness, taper, and radial clearance for the locating ring. outerLip / overhangOuter skirt depth and overhang for overlap-style lids. clearance / shrinkRadial fit allowance plus material/process shrink compensation. crown / wallLid rise, thickness, underside dish, and radial segments. handle.styleKnob, mushroom, loop, bridge, ring, fin, bud, or faceted block. handle.mountIntegral center, single boss, two lugs, ring saddle, or through-hole. ventOptional hole diameter and radial position for pouring vessels.

The panel model is intentionally exclusive: one editing context, one toolset, and one highlighted part at a time.

One open editor

Base, Spout, Handle, and Lid are mutually exclusive tabs. Switching panels preserves each part’s state and selection.

Persistent Scene bar

Visibility controls never move. Single-click toggles a part; double-click solos it. This provides assembly context without reopening another editor.

Active part gets editing affordances

Only the active part shows points, Bezier handles, attachment pads, dimensions, and warnings. Other visible parts are dimmed.

Preset first, custom second

Spouts and lid handles start from recognizable style cards. Selecting Custom exposes the point editor without forcing it on every user.

Lid is separate but composed

The lid can be shown seated, exploded, sectioned, or hidden. Its export button always produces a separate STL; “Export assembly” produces vessel and lid files together.

Progressive controls

Primary dimensions stay visible. Advanced fit, sweep, and mesh controls live in collapsed sections and inherit safe defaults.

Reuse the editor and sweep concepts already present, while isolating geometry so normal Vessel 2 export remains unchanged until an addition is enabled.

Preview vs. manufacturing mesh

Preview can render intersecting meshes quickly. Export must fuse attached parts, open the spout throat, and pass the shared watertight/manifold checks.

Backward-compatible files

Add a versioned additions object. Missing additions normalize to disabled defaults, so existing Vessel V2 projects load unchanged.

Independent history

Undo records the active addition namespace plus selection. Camera, visibility, and exploded view remain view-only and never alter geometry.

Two export products

Vessel export includes enabled spout/handle after fusion. Lid export remains a standalone closed mesh. Assembly export writes both with a shared project name.

Build the shared interaction model first, then add geometry in increasing order of manufacturing risk.

1
Composition shell

Add namespaced state, exclusive panel routing, Scene visibility, save/load normalization, and placeholder meshes.

2
Generalized editable path

Extract Vessel 2 point/Bezier/corner-radius behavior into a reusable 2D editor; migrate the handle concept without changing existing base behavior.

3
Handle on Vessel 2

Reuse the mug handle cross-section sweep and radius-at-height logic, then add arbitrary points and attachment pads. Validate the handle-only vessel export.

4
Spout presets and hollow sweep

Implement the ten centerline presets, mouth profiles, wall thickness, and preview. Then add throat cutting and fused export as a separate gate.

5
Traditional lid fit

Implement gallery, lid flange, outer skirt, fit clearance, shrink compensation, lid profile editor, and configurable handle mounts.

6
Combined validation

Test spout + handle fusion, separate lid mesh, old project loading, desktop/mobile panels, and the existing mesh diagnostics/performance gates.
